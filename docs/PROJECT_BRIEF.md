# Respiratory Gate Hospital Platform — Project Brief

## Objective

Transform `Elite_RT_Value_Calculator.xlsx` into a live, branded Respiratory Care management and service-line value platform.

The immediate target is not a full hospital information system. The first release should prove that hospital operational and financial inputs can be entered once and translated into transparent revenue, savings and service-line value scenarios.

## Hard constraint

Delivery window: weeks, not months.

Therefore:
- internal users first
- financial/operational model first
- no patient-level PHI in MVP
- simple role model
- minimal database
- calculation parity before advanced features
- external portals deferred

## Brand recommendation

Primary platform identity: orange/blue Respiratory Gate mark.

Use monochrome only as a secondary variant, particularly in dark surfaces or subtle branding.

## Core screens

1. Sign in
2. Overview dashboard
3. Hospital Inputs
4. Revenue scenarios
5. Savings scenarios
6. Value Bridge
7. Reports
8. Audit history
9. Settings

## MVP users

- Admin
- Hospital Manager / Finance
- Viewer

Physician and patient portals are later phases.

## Phase 2 candidates

- named scenario library
- richer filters and comparisons
- scheduled management reports
- equipment utilization workflows
- department KPI tracking
- physician portal (only after access model is defined)

## Phase 3 candidates

- patient-facing features
- clinical documentation
- interoperability / EHR integration
- predictive analytics
- advanced notification workflows

## Success test

A hospital decision-maker should be able to answer:

- What assumptions are being used?
- What hospital data is still missing?
- What gross respiratory service-line revenue is possible?
- What savings opportunities are quantified?
- What is merely a sensitivity rather than a forecast?
- What is the net value once operating cost is known?
